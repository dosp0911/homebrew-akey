# homebrew-akey

Homebrew tap for [akey](https://github.com/dosp0911/akey), a local secret store for AI coding agents.

```bash
brew tap dosp0911/akey
brew trust dosp0911/akey
brew install dosp0911/akey/akey
```

Homebrew only loads casks from third-party taps you have trusted.

`Casks/akey.rb` is updated automatically by akey's release workflow.
